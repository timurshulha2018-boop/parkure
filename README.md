# 🏃 PARKOUR 3D — Побег из Лавы

Крутой 3D паркур на Three.js с текстурами!

🎮 Играть: https://timurshulha2018-boop.github.io/parkure/

## Что в игре
- 3 уровня + 3 сложности (Легко / Средне / Хард)
- Текстуры: трава, камень, лёд, дерево, батут, лава
- Двойной прыжок, спринт (SHIFT), движущиеся платформы
- Скользкий лёд, батуты, чекпоинты, монетки
- Таймер, счётчик падений, звёздное небо

## Управление
- WASD / стрелки — бег
- ПРОБЕЛ — прыжок (можно двойной!)
- SHIFT — спринт
- Мышка (клик) — осмотр камеры

🟩 обычные • 🟦 лёд скользкий • 🟧 батут • 🔴 лава = смерть • 🚩 флаг = финиш
